# huokaingthara_football_about_us
⚽ Huokaing Thara Football Club (HTFC) Official Website

Welcome to the official repository for Huokaing Thara Football Club (ក្លឹបបាល់ទាត់ ហួកាំង ថារ៉ា). This repository houses the source code for our official bilingual website, designed to share club news, updates, training schedules, player recruitment, and leadership announcements with our fans and community.

📌 About Huokaing Thara FC

"Health lives in peace, and sport is for health." — Huokaing Thara FC Motto

Club Founder & Interim Coach: Mr. Huokaing Thara (ហួកាំង ថារ៉ា)

Head Coach: Mr. Seng Chhat (សេង ឆាត) (currently recovering)

Squad Target: 22-Man Roster

Training Ground & Recruitment Location: Olympic Stadium, Phnom Penh (in front of the old court / មុខតុលាការចាស់)

Official Website: https://tharahuokaing.github.io/huokaingthara_football_club/

🌟 Key Features

🌐 Dual Language Toggle (English / ភាសាខ្មែរ): Seamlessly switch between English and Khmer across the site.

📱 Responsive Design: Modern dark-theme UI optimized for mobile phones, tablets, and desktop devices.

⚡ Pure Web Stack: Built with vanilla HTML5, CSS3, and JavaScript — lightweight, fast, and dependency-free.

🏆 Leadership & Roster Showcase: Dedicated sections for coaching updates, player recruitment, and club background.

📁 Repository Structure

huokaing-thara-fc/
│

🚀 Getting Started

To run or customize this website locally:

Clone the repository:

git clone https://github.com/tharahuokaing/huokaingthara_football_club.git


Navigate into the project directory:

cd huokaingthara_football_club


Launch the project:
Open index.html or about.html directly in your browser, or use the Live Server extension in VS Code.
